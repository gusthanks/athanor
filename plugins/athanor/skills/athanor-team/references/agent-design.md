# Agent Design

## Core roles

Most projects benefit from one router or chief-of-staff role. Specialist roles
are conditional. Consider:

- product or domain expert;
- design and brand;
- engineering or operations;
- growth, sales, or support;
- finance;
- legal, privacy, safety, or regulation;
- reviewer or quality guardian.

Do not create all of them by default.

## Authority

Tools do not grant business authority. Separate:

- can read;
- can draft;
- can modify locally;
- can mutate external systems;
- can approve;
- can spend, publish, sign, or delete.

The last group remains human unless the project explicitly documents a safe,
lawful delegation model.

## Memory

Agent-private memory records verified working knowledge and tool traps. It is
weaker than live evidence, canonical sources, shared decisions, and role specs.
Shared facts must be promoted to a shared canonical source.

## Review

Review should test source choice, factual correctness, constraints, and
fitness—not merely add another subjective opinion.
